macOS 下载提示

首次打开可能提示“文件已损坏”

当前 macOS 版本暂未完成 Apple 签名与公证。如果出现该提示，请先将「览悟找图」拖入“应用程序”，然后打开终端执行：

sudo xattr -d com.apple.quarantine "/Applications/览悟找图.app"

执行后再次打开应用即可。后续完成签名与公证后将不再需要此步骤。

Windows 下载提示

下载或打开时，可能出现安全提示

请先确认安装包来自览悟找图官网，文件名为「览悟找图 Setup .exe」。如果来源或文件名不一致，请取消。

1浏览器询问是否保留文件如果看到“通常不会下载此文件”⌄

在下载列表中打开文件旁的菜单，选择“保留”；如果再次确认，再选择“仍然保留”。

2SmartScreen 阻止应用启动确认文件无误后再继续运行⌄

打开安装包时，如果出现“Windows 已保护你的电脑”，先点“更多信息”，再点“仍要运行”。
