安装与登录

安装后即可开始

首次打开后登录账号，新用户会自动进入 3 天试用。

下载安装包

在首页选择 macOS 或 Windows 版本。

安装并启动

macOS 支持 Apple Silicon，Windows 支持 Windows 10 / 11 x64。

登录账号

使用邮箱登录后即可进入软件。

建立图库

先让图片变得可搜索

选择本地图片文件夹并建立索引。索引完成后，图片无需移动，也不需要重新整理。

添加图片文件夹

选择你希望搜索的本地目录。

选择模型并开始索引

根据套餐和机器性能选择对应的找图模型。

等待索引完成

完成后即可直接用图片进行搜索。

后续替换为真实截图
相似图片

用一张图，找到相近画面

选择任意图片作为查询条件，软件会从当前图库或指定范围中返回视觉相似结果。

选择一张查询图片

可以从软件内选择，也可以从本地拖入图片。

选择搜索范围

可搜索整个图库，也可以限制到指定文件夹或分组。

查看结果

结果按相似度返回，可继续打开、筛选或加入分组。

人物搜索

用一张人像，找到同一个人

选择包含人脸的图片，识别人脸后即可在本地图库中搜索同一人物。

打开人物搜索

选择包含清晰人脸的图片作为查询。

选择要搜索的人脸

当图片中有多个人时，选择其中一个人继续搜索。

浏览人物结果

返回该人物在图库中出现过的相关图片。

人脸识别和搜索均在本机完成，原始图片不会上传到服务器。
局部搜索

只截一小块，也能继续找

当你只关心图片中的商品、人物、图案或某个局部时，可以直接框选区域进行搜索。

进入局部搜索

打开图片后选择局部搜索工具。

框选目标区域

只保留真正想搜索的主体区域。

开始搜索

软件会用选中的局部内容匹配图库中的完整图片或相关画面。

分组管理

搜索以后，顺手整理

搜索结果可以直接加入现有分组，也可以新建分组，不需要离开当前工作流。

选择图片

支持单张或批量选择搜索结果。

加入分组

选择现有分组，或直接新建一个分组。

继续搜索或整理

分组不会改变原始文件位置。

本地运行

图库和模型都留在本机

图片索引、模型推理和搜索均在本地运行。软件只需要账号与授权相关的网络访问，不需要上传你的图库。

如果机器配置较低，可以优先选择轻量模型；更高精度模型会占用更多 CPU、GPU 或内存资源。
